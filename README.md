# Девушка в цветущем мире

Мини-игра в стиле Genshin Impact: бег, спринт, прыжок, планер, сферы ветра, сакура, озеро.
Все кости VRM-модели анимируются (тело, руки, ноги, стопы, носки, глаза и все пальцы), волосы и юбка работают через spring bones.

## Файлы (кладите все в корень репозитория)
- index.html
- style.css
- world.js
- animator.js
- main.js
- girl.vrm  (22,8 МБ, меньше лимита 25 МБ для загрузки через браузер GitHub)

Весь проект около 23 МБ.

## Запуск на GitHub Pages
1. Создайте репозиторий, нажмите Add file, затем Upload files и загрузите все файлы.
2. Settings, затем Pages, затем Source: Deploy from a branch, ветка main, папка /root, Save.
3. Через минуту игра откроется по ссылке https://ВАШ-НИК.github.io/ИМЯ-РЕПО/

Управление: WASD, Shift, Пробел (в воздухе ещё раз — планер), F — помахать, мышь для камеры.
На телефоне: джойстик слева, кнопки справа.
